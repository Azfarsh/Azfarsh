### 🧩 How Axel AI works

Gemini produces structured plans, while pandas applies deterministic transforms. This keeps LLM reasoning separate from direct data edits.

```mermaid
flowchart LR
    U([👤 Natural-language goal]) --> A1[🧠 Intent<br/>Understanding]
    A1 --> A2[🗺️ Transformation<br/>Planning]
    A2 --> A3[⚙️ Sandboxed<br/>Execution · pandas]
    A3 --> A4[✅ Validation]
    A4 --> O([📦 Clean data +<br/>reproducible Python script])
    A4 -. retry .-> A2
```
